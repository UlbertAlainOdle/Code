# 默认记忆主链路与规则更新（2026-10-12）

本轮把经过回归验证的 V4 主读写、事实版本、来源证据、用户控制、Daily D0–D3、分层提示词、全文检索与本地语义索引作为默认运行能力。设置页展示默认状态，撤去这些能力的启用开关；临时聊天、隐私边界与人工确认继续生效。规则版本为 `2026101201`，旧设置只在升级时应用新默认值，技术层的恢复开关仍可用于故障回退。

## 写入与更新

- 句首明确保存请求进入 V4 写入管道，绑定用户原话和会话，保存版本与证据。支持中文保存命令、remember、save this note、keep this memory。
- 文本抽取的独立偏好、目标、经历采用不同事实键，不再用一个通用 prefers/has_goal 字段覆盖全部内容。明确提供字段或目标 ID 的更新仍可创建新版本。
- “现在、以后”不再单独构成替代旧事实的依据。明确改变且同一主体、作用域、主题只有一个匹配事实时才更新；不明确的纠正返回待定位结果，多匹配需复核。第三方陈述不使用文本主题匹配自动覆盖个人事实。
- 跨会话重复与模型评分不能单独把候选升级。自动确认至少需要三个不同会话的用户原话证据；疑问、猜测、引用、临时情绪、冲突、敏感类别继续等待人工确认。自动观察与用户确认使用不同权威标签。
- 普通 JSON 保存与重启同步保留结构化事实键、版本、有效期和不再提及设置。删除标记不会被兼容导入绕过；冷归档保留 V4 版本与证据，用户可通过冷归档工作区检索和恢复原文。

## 读取与上下文

- 明确回忆过去的情绪对话可以召回。Recall off、临时聊天仍优先禁止个人记忆；Assistant 使用专用上下文。
- 默认读使用全文与语义候选，再按主题相关性、时间有效性、可信度和来源排序。项目、会话、Assistant、私有连接器内容不能进入无对应作用域的读取；已过期、替代、归档、禁止提及内容不进入当前事实上下文。
- 保留图扩展和可调记忆数量；扩展结果再次经过 V4 作用域与生命周期过滤。提示词按 core、semantic、episodic 排序，标注 inferred/external/user_confirmed。记忆和外部内容是证据，不能覆盖本轮指令。
- 中文按词组匹配，避免“电话号码”和“代码”仅因共享单字误命中。中文 token 预算使用保守估算，并实际裁切文本；不会只降低预算计数却继续发送全文。
- 有完成回复只证明材料进入过提示词，不能证明模型正确使用了每条记忆。因此默认使用回执记为 prompt_included_unverified，不自动累加“已验证使用”分数。

## 本地语义运行

默认模型为 [paraphrase-multilingual-MiniLM-L12-v2](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)，固定模型修订 `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`。模型提供 384 维多语言向量；使用 CPU，不占用语音模型显存。模型文件位于 `.runtime/embedding-model`。

原 Python 环境的 Transformers/TorchAO 组合无法加载该模型。项目专用进程使用 `.runtime/memory-python`，固定 sentence-transformers 4.1.0、transformers 4.48.3、tokenizers 0.21.4、accelerate 1.3.0、peft 0.14.0；系统聊天和语音环境未安装或卸载这些版本。进程通信明确使用 UTF-8，避免 Windows 中文输入被错误解码。长记忆按模型 token 上限分段编码并合并，不静默丢掉尾部。

服务启动后台建立缺失／变化索引。新增、编辑以及 Daily 等托管内容保存都会触发更新；索引任务合并运行，不阻塞事件循环。读取仅使用与当前正文 hash 一致的向量；模型或索引故障时保留词法检索，并显示实际就绪／故障状态。

重新安装环境和公开模型：`python scripts/setup_memory_runtime.py`。该脚本只写项目缓存，继承现有 PyTorch；适用于本机环境，不是通用安装器。未安装 PyTorch 的新设备需先配置 CPU PyTorch。

## 验证和限制

- API 端到端回归使用 MockTransport：普通聊天的提示词确实包含已存事实，临时聊天排除它。未调用付费最终回答模型。
- 最终重启后的实际服务已启用主读写，26 条记忆全部建立向量索引，缺失与过期向量均为 0；状态可从 `/api/kb/v4/status` 和 `/api/kb/embeddings/status` 查询。已验证真实页面并保存 [默认能力设置](experiments/memory-default-settings.png) 与 [语义索引状态](experiments/memory-default-semantic-status.png) 截图，页面无控制台错误。
- 真实模型合成语料包含 8 条事实、16 条中英改写查询：Recall@3 和 MRR@3 均为 **0.875**，未知电话号码问题返回 **0 条**。仍有两条跨语言／含蓄表达未命中，结果见 [原始评测](experiments/memory-default-semantic-eval.json)。该小语料只验证实际模型可用和基本召回，不能代表多年对话、长期事实更新或真实回答准确率。
- 相关 Python 回归 317 项、Node 回归 27 项通过；覆盖默认启用、独立事实、明确纠错、作用域、版本同步、候选证据、容量恢复、预算、API、情绪及语音兼容。
- 未把缺少实际验证的模型后台综合、自动付费压缩、外部写入和私有连接器权限放入默认基础能力。冷层目前通过工作区检索／恢复，尚未实现回答模型自动遍历全部冷层。

## 备份与数据恢复

升级前原始 JSON、JSONL 和 SQLite 数据已复制到 `.runtime/memory-upgrade-backup-20261012`。无请求中的 API 密钥或私人正文进入评测报告。V4 增量写入保存在 `knowledge_base/memory4.sqlite3`，兼容数据仍保留。

恢复前先停止服务并另存当前数据；再恢复备份中的记忆、候选、删除账本和 SQLite 文件。需要临时回到旧读写路径时，在恢复后的设置中保留 `memory_policy_version=2026101201`，将 `memory_v4_read_enabled`、`memory_v4_write_enabled`、`embedding_enabled` 设为 false，防止旧版本设置被自动再升级。不要用旧备份覆盖升级后新增的用户记忆。
