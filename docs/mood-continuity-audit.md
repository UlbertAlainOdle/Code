# 情绪连续体检查与修复

**2026-10-10 更新：聊天改用会话消息快照。** 每轮数值独立保留，只在同一会话内延续；颜色圆点和悬停直方图替代文字标签。轮询不再推进时间衰减；历史朗读使用当轮快照，自动朗读等待最终快照。规则、旧记录估计和验证见 [聊天体验刷新记录](chat-experience-refresh.md)。下文保留旧版全局引擎审计，仅适用于未指定会话的兼容接口，不再是聊天界面的状态来源。

输入框旁的情绪标签现在可以点击，进入 **Companion 陪伴 → 情绪连续体**。此页提供“解除情绪锁定 / 锁定当前情绪”和“恢复平静并解锁”。

解锁保留原有快乐、活力、压力数值，重新从当前时间开始变化。锁定期间积累的时间不会在解锁瞬间把心情清空。“恢复平静”才会主动设为快乐 50、活力 50、压力 0。控制按钮即时保存；“启用情绪连续”的选择仍通过页面“Save & Apply”保存。

本次修复：

- 恢复锁定控制，并保留输入框标签的键盘可操作性。
- 关闭连续功能后，聊天不再更新心情，也不再给模型附加心情语气上下文。
- 普通 API、本地聊天和 Agent 都接入相同的心情上下文；Assistant 角色保持独立。
- Agent 直接回答和优先动作播放期间也捕获回复中的 MOTION 情绪标签，情绪更新不再依赖是否播放了动作。
- 查看状态时推进闲置回落并重算显示标签；频繁轮询不会重置回落计时。
- 锁定时冻结数值和时间回落；解锁恢复时间基准。
- 状态保存改为原子替换，相关修改串行执行；保存失败返回错误并回滚内存状态。
- 锁定接口严格接受布尔值，避免把字符串 `"false"` 当成真。

当前能力的边界：这是一套由 Saya 回复里的 `[MOTION: ...]` / `[MOOD_SAYA: ...]` 标签驱动的数值规则，不是独立的情感识别模型。没有有效标签的回复无法产生对应的对话增减，只能自然回落；模型对语气提示的遵从程度仍取决于模型本身。动作选择仍以每条回复的 MOTION 标签为准，连续心情只是其语气背景。

Qwen3-TTS Base 克隆没有正式的独立声学情绪参数。“表达实验”在流式加速后端把当前 dominant 映射为模型 `instructions`，保持固定参考、正文和采样参数；原生明确拒绝非平静模型指令。旧变速方案和 ICL 指令的负面情绪未达到听感要求；加强指令 + 仅音色向量经用户确认“明显更好”“仍像 Saya，可以采用”。本地已开启该原型，平静和各心情统一使用原参考的音色向量，效果仍可能因文本而异。锁定沿用当前心情，关闭连续功能时自动朗读使用平静；Assistant 不读取陪伴心情。一次朗读冻结开始时的心情，后来出现的回复标签在下一次朗读生效。试听、失败案例和采用记录见 [原型记录](qwen-mood-prototype.md)。

验证覆盖解锁后更新与重启读取、锁定冻结、闲置回落和标签重算、关闭开关、错误参数、保存失败回滚、本地提示构建、模拟 API 流及已有陪伴功能回归。模型响应使用模拟数据，测试不调用付费服务。
