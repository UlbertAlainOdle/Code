# R5 联合视图 QQ 实机验收

在主人 QQ 好友私聊使用虚构材料。每条命令或消息等到完整回执再继续。出现无回复、意外正文或权限提示时，停在该步并回报当时的回复。

## 保存两条独立样本

1. 发送 `/context new`，等待新话题回执。
2. 发送 `这是虚构的 R5 验收材料。杉栈温室在白天使用蓝色标记。`
3. 发送 `这是虚构的 R5 验收材料。杉栈温室在夜间使用橙色标记。`
4. 发送 `请把我刚才说的两条虚构验收材料，分别保存成两条长期记忆。` 如出现选项，只选上述两条原话。完整预览中两条都正确时发送 `记住`，记下实际返回的两个完整记忆编号。

## 预览、查询和撤销

1. 发送 `/memory link 第一个完整编号 第二个完整编号`，编号包含各自的 `memory:` 前缀。核对两份完整来源，以及白天蓝色和夜间橙色仍分别呈现。
2. 直接发送预览末尾的 `/memory link-confirm 操作编号`，保留实际操作编号。收到已确认回执后，等待平时的消息冷却，再发同一条确认命令。两次都应返回同一操作编号。
3. 分别用 `/memory link-show 第一个完整编号` 和 `/memory link-show 第二个完整编号` 查询。两个入口应显示同一联合视图。可用 `/memory link-result 操作编号` 核对状态。
4. 发送 `/memory link-undo 操作编号`，等待撤销回执。再查一次 `/memory link-result 操作编号`，应显示已撤销。两个原条目仍可用各自的 `/memory show 完整编号` 核对。

把联合视图操作编号和最后结果发给我。先保留两条虚构样本，等我核对实际入站、送达、确认账本和两个原编号后再清理。这个实验覆盖主人私聊联合视图。个人事件和群协调人路径分别保留自己的验收范围。
