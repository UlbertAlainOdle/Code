新增原桥接库`qq_person_event_source_guards`及history schema，按bot/真实主体/来源范围/原话hash保存来源失效状态，**不另存正文、标题或私密摘要**。更正、后续更新、旧事实掉出8项窗口、删除和来源过期均能阻止旧原文回填；hash元数据随原QQ会话保留窗口清理（配置原值保留），每bot最多16000项，满额在模型调用前拒绝新证据，不能靠删除旧保护来放行。不是无限保存完整旧聊天或延长群原话保留期。

QQ响应器对普通历史、生成器重新加载、时钟行、共享群历史（含其他说话账号）和已选网页档案执行同一过滤，关联的下一条AI回复也移除。后续派生历史、群引用和待发结果携带hash版本快照；并发更新、删除、epoch/范围/过期变化使旧结果失效。关闭事件功能也不能解除已知失效来源保护。旧群原始记录/网页原始档案仍保留，不批量改写聊天。

当前有效事件的旧日预算改为逐条装入最新事实，达到预算时保留已经放入的最新项；不因同一卡积累多条旧事实就整卡退出。事件提示明确：cooling是关注状态，未过期安排仍能回答“原定什么”，不等于已经完成；引用他人说的“更正”不能取消本人的有效安排。
