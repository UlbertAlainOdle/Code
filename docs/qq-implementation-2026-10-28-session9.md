# QQ 第九轮：自动搜索与自主工具路由修复

日期：2026-10-28。分支 `codex/qq-message-bridge`。前序实现和门禁见[实施进度](qq-implementation-status.md)。

## 原因与交付

线上QQ搜索模式为`auto`、自主工具为`true`。此前适配器只有`force`和显式命令会选择固定研究流程，其他共享主人问句进入自主规划；通用生成器在自主规划时关闭固定研究，搜索工具虽可用，模型仍能不调用工具而直接生成离线回答。网页自动研究的触发判断因此没有保障这条QQ路径。

`saya_app/services/qq_chat.py`现在直接复用网页`web_research.policy.should_research`，在权限和命令解析之后决定：命中`auto`规则或`force`的请求走既有固定Search/Fetch链路，普通聊天继续保留自主工具。不会并行启动两个控制器，不添加另一份新闻规则，不修改已保存的开关。记忆召回/预算/保存参数仍原样传给公共生成器；`off`不自动研究，显式`/search`保持单次强制语义。

群/非主人搜索权限没有扩大；主人关闭共享长期记忆仍可按既有规则联网，但不因此获得个人记忆。没有跨端近期历史共享，前轮历史隔离保持。这是QQ-01兼容缺陷修复，没有启动QQ-03～08。
