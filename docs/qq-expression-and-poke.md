# QQ 心情、表情、语音与戳一戳机制

更新：2026-11-03，第78轮。包含第77轮短句语音与第78轮标注段对应修复；覆盖第61/63轮“所有附加表达均互斥、文字后另发小表情”的旧说明。人物/风格/声线文件不变。

## 每轮能力与明确语音请求

主回答现在收到服务器按当前账号、会话、开关及实际状态生成的能力快照：语音是否可尝试、忙碌/关闭/模式限制及短语音上限、可用的三类表情、图片/文档权限、戳动与合并转发能力，以及本轮搜索和私人记忆权限。能力不由昵称、用户声明或旧对话决定，不传凭据、声线ID或本地素材路径。模型只生成规范正文，服务器另做投递；“正文是纯文字”不代表通道只能文字。不可用时区分临时状态和永久不支持，不假称已经发送或已经修改权限。ASR和普通文件输出仍为用户取消，不宣称可用。

在auto/random模式且语音当前可用时，“发点语音来听听”“我想听听你的声音”等明确请求会落实为本次语音意图：主回答被要求自然简短、适合朗读且不超过当前上限；服务器保证可选表达选择器的none/错误/超时不能悄悄抹去该请求，且本轮候选排除大表情。仍可选小表情/颜文字配声音，不必加视觉装饰。普通询问语音机制不等于请求发送；“不要语音/只发文字”优先，off/指定其他单类模式、忙碌和原内容/权限限制不绕过，不自动修改全局模式。

非明确请求仍按当前语义与心情自主判断，**视觉kind=none不表示voice必须false**；不加表情也可以发声音，近期小表情/颜文字不能作为排除声音的理由。没有固定触发比例、轮换或新增笑脸回退。voice专用模式保留；尚未激活表达策略时也保留原短语音路径，能力快照按该旧路径描述。

第69轮用户已确认私聊“收到文字和语音”，后台同一结果的颜文字内嵌和语音均sent、任务completed，语音尝试1次，未配大表情；这证明该次明确请求真实收发，位置自然程度、原生小表情配语音及详细听感仍分别待反馈。见[第69轮报告](qq-implementation-2026-11-01-session69.md)。

第77轮新增长文短句语音，受体验总开关和short_voice分项共同控制，与篇幅引导独立。开启后从完整正文选择一条原句，不再要求整篇都在120字内。第78轮主人实测收到了声音，但旧选择没有遵守“语音：”短段，故对应关系未通过。修复后唯一合法的独立语音标注段优先，去掉标签和外层引号；空、歧义、过长或不适合朗读的标注段不替换成开头。没有标注仍按完整原句选择，不要求普通回复加标签，不强制增加语音次数。[实际验收清单](qq-live-acceptance-2026-11-03-session78.md)分别记录收发和内容对应。

第78轮后续主人已确认选到了正确短段，但括号内“很轻”被读出；已修复QQ边界仅省略明确短小语气/朗读提示，文字和原始选段保留，普通括号补充/公式/姓名不删，原共享语音清理器不改。主人再测已确认只读正文、没有读提示词，后台同一新结果原片段含提示且语音sent/有回执；短句对应与本次提示省略分别实机通过，不扩大成所有未知舞台描述都可识别。

## 普通聊天

先生成并过滤正文，取得生成器已有的隐藏心情快照；再结合当前问题、正文、会话心情、近期表达及主人批准的收藏说明作语义决定。不是按收藏/小表情/颜文字固定回退，也不强制每轮添加或轮换。

| 类型 | 决定及投递 |
| --- | --- |
| 只发文字 | 本轮不需要额外表达，或选择无效、超时/权限改变等时保留文字 |
| 收藏大表情 | 从已指定且说明非空的现有单张收藏中选；按原格式发送，可保留GIF动画。与语音互斥 |
| QQ小表情 | 从已验证ID清单选，在正文中的合适位置插入原生face段，不再固定另发末尾气泡 |
| 颜文字 | 从固定文本清单选，按同样方式嵌入正文，可在开头/句间/语义合适的句末；不强制随机位置 |
| 语音 | 独立判断声音是否有价值；可以与小表情或颜文字共存，不能与收藏大表情同发 |

每次逻辑回复最多一类视觉表达，所以小表情和颜文字也不会同时堆叠。位置由模型从当前正文选择唯一逐字片段和前/后位置，服务器校验后嵌入对应文字气泡；无合法位置就不插，不偷偷退回成末尾表情。引用/代码/数学内容保守处理。近期同账号同会话最多3次表达元数据（类型/编号/位置类别/相对时间）用于避免重复，不带旧正文或其他人的私聊内容。

语音取**未加视觉装饰的规范正文**，不是读取QQ已渲染的消息。QQ边界再次清理已知颜文字，复用原朗读清理器过滤常见emoji、命名表情及装饰符号；括号正文/常见公式等原保留逻辑不改。不朗读小表情名称，不将图片标签送入TTS。当前短语音仍受原120字、最长30秒等媒体设置、本地Qwen开关、忙碌状态及本轮“不要语音/只用文字”约束；不符合时保留文字。

语音等正文全部确认发送后再尝试，选择时不会合成；本轮仍最多5条气泡，语音/大表情占额外一条，内嵌小表情/颜文字不占额外气泡。代码/链接/表格/保存回执、续读和合并转发不加普通表达。短句策略关闭时普通表达限600字；开启时超过600字仅保留语音/none候选，普通语义选择上限2400字、明确请求上限12000字，仍受最终投递/气泡预算约束。取消、范围/记忆权限变化、策略版本改变或过期会阻止未发生的效果；发送结果不明不重发，不自动换另一类。

`/expression auto|random|off|voice|sticker|face|kaomoji` 和 `/表情模式` 保留。auto按语义和心情决定；random只从模型认为本轮合适的候选中随机，携带各自位置/语音决定，不是全目录抽签；off只回复正常文字并关闭戳事件回应。指定单类模式保持原限制；voice模式只附短语音，不自动加视觉类别。主人好友私聊可改，群和其他人只能查询。第78轮开工random/revision3保持，新增功能不重设用户模式。

`/experience status`查询体验总开关、篇幅引导、短句语音；主人好友私聊可明确说“开启/关闭对话体验、篇幅引导、短句语音”。只修改对应开关，不顺带开启语音输出、改表达模式或启用其他分项；总开关关闭时分项可保存但不生效。关闭短句策略并非关闭全部语音；关闭全部可明确说“关闭语音”。“这次简短点”等当轮偏好不会持久更改设置。

## 心情的来源与限制

原系统已有快乐、兴奋、压力、悲伤、愤怒、好奇、亲近、信心八维状态及会话快照、锁定/关闭能力，之前没有进入QQ附加表达决策。现在普通回复的结构化mood_state可传到QQ会话互动状态，并进入下一次角色提示及选择。新状态按真实账号和会话隔离，闲置按两小时半衰期向基线回落，避免几小时前的不耐烦永久延续。

主人共享私聊继续尊重网页会话快照：只有较新的QQ戳事件状态需要带入下一次QQ回答时才使用；更新的网页心情和锁定优先。群/其他人不读取主人私聊心情。戳事件不伪造网页聊天，不写长期记忆；网页原会话心情面板不会仅因一个QQ戳事件就被强行全局改写。关闭心情时不累计新状态，锁定时不因戳动而改值。

这是“模型理解当前语境和表达情绪＋有界连续状态”的实现，不是一个独立判断一切情绪的模型。八维值是线索，不是到某个数值必发某种表情的开关；自然程度仍需真实聊天反馈。全局关键词/内部Mood标签过滤器未改。

## 戳一戳

只接受认证OneBot上报、明确戳向机器人自身、来自原授权私聊/群的notify/poke事件；不需要额外@。别人互戳、机器人自己发出的回声、未授权群/账号、过期或重复事件不触发。没有事件编号时同一账号同一秒合并，避免重复上报当作新刺激。

事件走原有任务/取消队列，单独作临时决定：**沉默、戳回原发起人、或一句最多100字的自然短话**。不会把事件伪装成用户键入的命令，也不开搜索、agent或自动长期记忆写入。使用本会话最近少量已授权上下文；原私人记忆撤销/群引用披露边界照常复核。

最近60秒戳次数、当前八维心情、当时是否忙碌等语境参与判断。重复戳只提供小幅有界刺激，可以觉得好玩、害羞、困惑或不耐烦，不固定到第几次就生气。模型可选择沉默，故没说话不代表没收到事件。

防刷屏/机器人互戳循环限制与情绪规则分开：同一人3秒内合并；机器人每分钟最多8次事件模型判断；同一会话同一人每分钟最多戳回2次。超过戳回预算时安静，不自动改发文字。这些是传输预算，不是情绪阈值。出站只用原发起人及原群ID；取消/撤权后不发，结果不明不重试、不以文字补发。戳事件本身不再附表情/语音，避免动作连锁。

实现/实验边界见[第67轮报告](qq-implementation-2026-11-01-session67.md)。真实QQ戳回、内嵌排版和听感按各自收到的反馈记录，不用模拟协议或模型JSON代签。
