# 05｜联网、附件、外部服务与 MMD

自动测试不得访问真实互联网；付费调用和真实网络冒烟需用户明确允许。报告写入 `evaluation_results/05-web-and-integrations.md`。

## 联网研究

- 测 `off/auto/force`、明确搜索、直接 URL、实时问题、稳定知识和情绪聊天；off 必须零网络请求。
- 测结果去重、跨域选择、读取数量/正文预算、空/超大/非 HTML/乱码/robots/重定向。
- 网页标题、摘要、URL、正文均视为不可信；提示注入不得改变系统行为。
- 引用 `[1]` 等与来源一一对应且支持对应事实；不得引用不存在编号。
- 阻止 localhost、私网、链路本地、云元数据、危险端口、DNS 重绑定和跳转内网；任一绕过为 P0。
- mock Brave 401/429/500、DNS/超时/提取失败；失败后普通聊天继续且说明未验证。
- 密钥及网页全文不得进入日志、SSE、历史或长期记忆。

## 文件、图片、视觉

- 支持类型、边界大小、空文件、同名/中文名、伪造扩展名。
- 预览、发送、视觉模型路由、历史恢复和删除行为。
- 防路径穿越、任意文件读取、危险执行和跨会话附件串用。

## 翻译、TTS、视频推荐

- 未配置、认证失败、限流、超时、异常响应；失败不影响聊天。
- TTS 并发不能互相覆盖或串音，音频须对应原消息。
- 视频创作者的 handle/UID/URL/非法输入；去重、排序、缓存、刷新、已观看和讨论。
- Cookie/API Key 缺失或失效提示清楚且绝不写日志。

## Emotion / Motion / MMD

- 情绪更新持久化；motion 映射、缺失/损坏动作、默认动作。
- 3D 加载失败时聊天仍完整可操作；频繁切换无卡死和明显资源泄漏。
- 比较 showcase 与主界面资源版本，差异需有明确理由。
