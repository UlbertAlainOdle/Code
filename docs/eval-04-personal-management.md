# 04｜项目、目标、打卡与 Daily Brief

报告写入 `evaluation_results/04-personal-management.md`。

## 项目

- 新建、重命名、选择、删除；新会话绑定当前项目。
- 同项目近期上下文可用，其他项目专属信息零串线。
- 删除/解绑项目时会话和记忆处理明确；测空项目、大量项目、同名和特殊字符。

## Goals / Life Quests

- 新增、编辑、完成、重开、删除。
- 目标、check-in、记忆摘要的稳定 ID 与关联一致。
- 重复同步不制造重复目标/core 摘要；状态变化能反映到聊天。

## Daily Check-in

- 固定/单日任务以及每日、工作日、周末、每周、每月频率。
- 跨日、月、年、闰日，重点检查 Asia/Shanghai 午夜前后。
- 完成/部分/错过颜色和统计；心情、精力、难度、备注保存恢复。
- 月/年汇总与 Markdown/JSON 导出能从原始数据重算且一致。

## Daily Brief 闭环

- 卡片增删改排及刷新恢复；读取失败时降级。
- “Talk with Saya”注入当天与汇总，但隐藏上下文不显示成用户文本。
- 检查目标、打卡、项目、记忆的重复、过期和矛盾上下文。

最低验收：日期不因 UTC 偏移错一天；统计可重算；项目零串线；重复保存不重复；删除影响范围在 UI 中清晰。
