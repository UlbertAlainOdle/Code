# 03｜Memory 3.0 质量、隔离与恢复

只使用隔离副本，报告写入 `evaluation_results/03-memory.md`。

## 固定数据集

创建至少 40 条合成记忆：10 条 core 身份/偏好/边界，10 条 semantic 事实/项目决定/目标，10 条 episodic 时间事件，5 条互相纠正或冲突信息，5 条 archive/不应召回信息。覆盖中英、同义词、错别字和近似主题。保存数据及期望命中 ID，禁止使用真实隐私。

## 任务

1. 测新增、编辑、归档、恢复、显式删除、锁定、星标、标签、层级筛选、重复写入和旧格式迁移。
2. 测精确词、同义改写、跨语言、时间、项目和否定查询；记录 Recall@K、Precision@K、MRR、无关注入率、冲突召回率。
3. 分别评测 FTS、可用时的 embedding、混合召回、关闭 Memory 3.0 的兼容模式。
4. 检查 token 预算；core 不得挤占全部上下文。
5. 新事实纠正旧事实后应优先新事实并保留证据链。
6. 项目 A 专属内容不得注入项目 B/普通聊天；archive 和墓碑删除不得重启复活。
7. 比较 JSON/SQLite 的数量、ID、状态和关键字段。
8. 模拟 SQLite、FTS、embedding 不可用，验证不改数据的安全降级。
9. 在副本模拟中断写入或损坏，验证备份、完整性检查与恢复。
10. 重建索引不得修改正文、删除记录或改变稳定 ID。

## 建议阈值

精确与近义查询 Recall@5 ≥ 0.90；项目串线率、删除/归档误召回率均为 0；最新有效事实排名高于旧事实；注入不超预算。所有失败必须附具体查询、期望 ID 与实际 ID。
