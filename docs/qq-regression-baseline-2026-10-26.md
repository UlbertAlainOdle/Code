# QQ 回归基线与兼容约束

日期：2026-10-26。用途：为八项升级保存当前行为边界，防止新能力覆盖旧功能。

配套：[实施编排](qq-roadmap-2026-10-26.md) · [验收矩阵](qq-acceptance-2026-10-26.md) · [工作区清单](qq-baseline-manifest-2026-10-26.json)。

## 1. 基线的证据范围

本文件来自当前源代码的只读核对。本次没有重新运行模型、QQ 收发、网络搜索或业务回归，也没有改变线上配置。

Git HEAD 为 `2940618db653a70e4fb4b3bef007c04758ccd4c8`，分支为 `codex/qq-message-bridge`。工作区包含未提交修改，所以 HEAD 本身不是完整功能快照。选定业务文件的哈希和已保存非敏感开关见 JSON 清单。

哈希用于识别版本和定位差异，改动后的哈希变化本身不是失败。回归判据是下面的行为、接口和数据约束。

2026-10-24 的旧报告中有 64、80 等历史测试数字和早期功能描述；前次实施另有 180 项相关验证记录。后续必须按当时实际代码重新执行，不能把任一历史数字直接写成当前阶段 PASS。

| B17 | 去重、冷却、队列容量与过期检查 | 重复消息不重复生成或保存，忙碌有可识别结果 |

| B19 | 重启恢复未执行且未过期队列 | 生成中断和发送不明不自动重放 |
| B20 | 文字以 OneBot text 段发送、群回复 @提问者 | 模型文本不会变为协议操作；可安全降级为纯文本 |

| B24 | 网页普通聊天复用原模型、会话与记忆链路 | QQ 改动不能使网页无法发送、读取记忆或隔离临时聊天 |
| B25 | 失败通知及不含正文的诊断 | 不向 QQ/公共状态暴露密钥、接口堆栈或其他会话内容 |
| B26 | QQ 接入与本机 NapCat/Saya 两个运行进程关联 | 关闭浏览器不应关闭机器人；错误停止不得影响其他工作区进程 |

2026-10-28用户明确调整B16的QQ显示策略：正常回复隐藏厂家能力说明和默认来源，内部证据、引用校验及告警保留；主动索要链接时可显示，真实失败仍简短可见。该用户新要求优先于旧测试的“每次附来源”断言；网页来源行为不改，见[第十轮报告](qq-implementation-2026-10-28-session10.md)。

## 3. 已知限制，不能误报为已实现

- 文本之外的图片、语音、文件尚未形成完整接入；引用与群多人语境不足。
- 任务控制与最终回复共用现有串行流程，尚无完整的高优先级取消通道。
- 长期记忆共享不等于网页与 QQ 最近对话自动连续。
- QQ 设置和网页普通聊天仍有独立偏好；搜索凭据存在手动同步步骤。
- 记忆修改、删除、冲突管理与召回解释还没有完整 QQ 交互。
- 持续在线守护、登录失效提醒、可靠的长答案续读属于规划项。
- 上次实测未发现搜索密钥；2026-10-26 本次未重新检查运行环境，不能据此判断今天是否已配置。
- 原始记忆记录不一定全部可召回：日常活动独立管理，删除、无效、不完整或范围不符条目不得仅因“多读一些”重新引入。

## 5. 每阶段必须执行的保护流程

1. 开工前保存本阶段代码/配置版本；核对基线测试文件和关键断言仍存在。
2. 同一阶段只引入必要的共享接口变更，不把业务重构与新功能混在不可拆分的改动中。
3. 当前生产数据不用于故障注入。测试库、凭据、缓存与模型接口均隔离。
4. 核心基线先在模拟模型、模拟搜索与模拟 OneBot 下执行；再运行所有已经交付阶段的新增测试。
5. 受影响网页入口和纯文字 QQ 入口均做冒烟。涉及媒体或群时不能只验证新类型而跳过原文字流程。
6. 新功能关闭时重跑旧路径；失败要证明不是依靠新功能开关才能维持旧聊天。
7. 做升级、重启、回退演练，并核对设置、群授权、消息去重及长期记忆没有丢失。
8. 保存证据和遗留限制，门禁未过不得将下一任务标成进行中。

## 6. 数据、环境与证据规则

- 备份 SQLite 使用一致性快照或 SQLite backup API；存在 WAL 时不能只复制单个 `.sqlite3` 文件。
- 私有数据备份在本机受控目录保存，不放进公开文档或版本库。文档仅记录时间、版本、脱敏摘要和恢复结果。
- 模型与搜索单元测试使用假凭据，所有网络出口应被模拟；回退路径也必须被模拟，防止测试意外访问真实 API。
- 真实验证必须先核对目标机器人与测试群；不使用日常生产群做杀进程、重复发送或权限泄漏实验。
- 截图、日志和测试报告不包含密钥、二维码、完整私聊、原始记忆或未脱敏附件。
- 脱敏不能把失败信息全部删掉：仍需能定位用例、版本、范围、状态和实际结果。
- 回退不等于恢复整个旧知识库。用户在升级期间新写入的合法数据需要保留或对账，不能直接覆盖。

## 7. 发布阻断条件

任一项出现即阻断发布：私人信息跨人/群泄漏；网页基础聊天失败；旧命令失效；已有设置被默认值覆盖；不确定发送被重复重放；未确认的记忆变更；只读限制被绕过；进程误杀；测试真实网络未隔离；基线断言被删改以换取通过。
