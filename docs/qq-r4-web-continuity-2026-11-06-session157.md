# R4 普通网页、预算与接续检查（第157轮）

日期：2026-11-06，America/New_York。接续[第156轮基线](qq-r4-recall-baseline-2026-11-06-session156.md)。R2/R3保持签收；本轮不签实际浏览器、实际QQ或整个R4，不启动R5/R6。

## 已补的合同

普通网页关闭Agent时，自动召回原先只认“记得、之前”等词，直接询问自己的选择理由会漏过。新增保守的本人既有选择/带时期状态识别；一般原理、建议、引文和陈述不因一个“我”就触发。关闭召回仍优先，旧明确历史触发合同保持。

提示编译器记录实际可用、纳入、遗漏及截断的数量和ID；先预留定长回执，再在原预算内编排。长记录不得挤掉回执却留下无法解释的事实碎片。预算和预览上限裁剪只保留完整句/分句，没有完整单位就省略并明确登记；不把半个词当完整理由。匹配过但未进入提示，和本次未匹配分开。理由片段截断、回指对象尚未确定也有不同状态；不把它们写成“没有理由”。

V4已计入预算的回答规则可从材料中拆出，作为普通API独立系统消息传入；本地分支使用同一主机规则。没有复制一份规则来扩大额度，默认适配器合同仍兼容。候选和未知报告不冒充个人事实，当前选中版本不证明此后没有更新。

一个明确命名对象确实匹配当前有效候选时，排除其他对象；明确询问本人选择时，排除其他主体。只在原权限、生命周期和有效期检查后收窄，不扩大读取。多个命名对象不做单对象过滤，近似对象仍保留双方供分别回答或澄清。规则没有写入任何实验项目名；这仍是保守词面选择，不是通用语义归属证明。

明确说“换一个话题”且当前对象有实际证据时，只改变本轮模型历史视图，不删聊天文件；返回旧话题可重新读取原历史。检查发现时间元数据的`message_hint`也带正文，因此同一视图同时用于普通历史和时钟提示，保留当前时间、上一轮时间和间隔等事实，不让旧话题从时钟提示重新进入。指代不明确时不擅自清空历史或硬选对象。
