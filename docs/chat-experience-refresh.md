# 聊天体验与会话心情（2026-10-10）

本轮将公开处理进度、最终文本和本轮语音心情串成同一条链路。Qwen 沿用用户已试听认可的固定 Saya 音色向量及 v3 表达指令，保持原参考声音与采样配置。

## 使用行为

- 发送后立即显示处理卡片；实际搜索、读取来源、工具调用、模型分析和组织回答事件加入记录。正文先缓存在前端，收到 `answer_complete` 后完整展示；停止时显示已经生成的部分。完成后可展开处理记录。
- 思考选项为自动、关闭、轻度、深度、最高。生成时显示停止按钮，结束/错误/取消后恢复发送按钮。
- 每条回复下方的喇叭负责播放或停止。点击另一条回复会中断上一段音频和后续生成；过期任务结束不会清除新喇叭的播放状态。
- 每条 Saya 回复保存八维数值快照：快乐、活力、压力、低落、愤怒、好奇、亲近、从容。珠光情绪球通过多层径向渐变、环形色带、暗部和高光混合这些数值；悬停或键盘聚焦显示两排四列的 0–100 直方图。输入框读取当前会话最新快照；切换、截断、分支后按保留的历史恢复。
- 输入框分成上方文字区和底部工具栏。上传、思考、上下文进度在左侧；心情球紧邻右侧发送/停止按钮。统一中心线与按钮尺寸，多行输入不会推移某个控件，窄输入区自动收缩辅助标签。

## 思考参数

根据 [DeepSeek 官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)，OpenAI 格式使用 `thinking.type=enabled/disabled` 和 `reasoning_effort=low/high/max`，自动采用服务默认档位。最高档可能增加延迟和 token 消耗，正文等待上限为 600 秒；其他思考档使用现有深度回答等待上限。

目前只为官方 `api.deepseek.com` 的 DeepSeek V4 / Flash 启用档位。其他模型及转发接口未验证这些字段，选项禁用并发送自动；不改变原 API 配置。多模态、Assistant 强逻辑或深度记忆模式按实际最终回答模型判定。仅显示公开处理状态，不展示或保存原始 `reasoning_content`。Agent 规划和后台记忆整理保留各自模型策略，选项控制最终回答。

## 心情与文本、语音的联动

`conversation_mood.py` 以上一条快照为起点，向本轮有效表达标签的八维目标插值。每轮压力最多变化 28，其余维度最多变化 22；重复标签收敛到目标，不会不断累加至上限。没有有效标签时每轮向初始值回落 8%。查看、轮询及闲置时间不改变历史。

好奇控制探索意愿，亲近控制温暖程度，从容控制表达稳定性，不能据此提高事实判断的确定性。低落和愤怒独立于压力。模型可返回 `curious`、`affectionate`、`confident` 表达标签；它们分别沿用已验证的中性、开心、中性语音指令。八个数值全部进入回复提示词，但 Qwen 的声学控制仍采用现有有限表达类别，不能独立调节八个声学参数。

请求前快照进入最终提示词和 Agent 上下文。回答中的 `MOOD_SAYA` 优先于 MOTION 决定表达，保存回复后发出同一份 `turn_mood` / `answer_complete` 快照。连续数值表示背景心情，`speech_mood` 表示本轮表达：一次紧张表达可以立即采用紧张韵律，同时背景压力平滑变化。

历史重播、自动朗读及所有音频分块冻结该回复快照。自动朗读等完整回复和快照确定后开始，音频仍可 PCM 流式播放。Assistant 使用中性语音；关闭情绪连续功能暂停数值变化、语气提示和自动情绪语音。

取消或生成错误保留开始前的心情，不把半截回复当成新情绪。锁定/恢复初始值只作用于所选会话，控制信息保存于该会话 `.mood.json`，不改写旧消息。恢复初始值主动覆盖下一轮起点，之后新快照再次成为连续性的依据。

## 限制与验证

- 仍是模型表达标签驱动的数值规则，不是独立情感识别模型；缺少可靠标签时无法准确识别语境。“完美联动”不能等同于声学表现已经逐句验证。
- 旧消息缺数值时根据可用旧标签重建并标明“历史估计”；没有标签时沿用初始/上一估计值。三维旧快照原值不变，只有新增维度标记为历史估计；八维新快照版本为 3。不会覆盖旧 JSONL 文件，旧恢复初始值的侧文件也继续有效。
- Qwen Base 表达指令仍是实验能力，难过/紧张可能因文本而异。固定音色方案见 [原型记录](qwen-mood-prototype.md)。
- 实际页面已检查历史控件、输入框最新状态、八维键盘聚焦直方图及不受支持接口下禁用的思考选项。在 620×542 和 1280×800 视口检查单行/多行输入与工具栏，各控件中心线一致；临时视口覆盖已恢复。实景见 [输入框与情绪光谱](experiments/chat-spectrum-composer.png)。
- 后续按界面反馈将光谱面板收为 208px 宽、约 226px 高，柱条由 24px 收为 10px，保留两排四列与所有数值。更紧凑的内边距、暗色玻璃背景与细边框减少遮挡；仅调整样式。1280×720 实际页面确认八维完整、面板在视口内，见 [紧凑光谱](experiments/chat-spectrum-compact.png)。
- 159 项 Python 与 27 项 Node 回归通过，覆盖会话隔离/分支、三维历史升级、旧控制侧文件、八维提示词、精确数值接口、API 流、取消快照、网页研究、历史重播、播放互斥、PCM、进度、按钮、思考参数与轮询时的悬浮面板稳定性。外部聊天响应使用模拟数据，本轮未调用付费聊天 API。

实现入口：`static/js/chat_experience.js`、`app.js`、`voice_settings.js`，`saya_app/services/conversation_mood.py`、`api_thinking.py`、`task_progress.py`，以及聊天/心情/语音路由。
