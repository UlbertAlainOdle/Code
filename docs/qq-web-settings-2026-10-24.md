# 网页 QQ 设置更新

日期：2026-10-24。分支：`codex/qq-message-bridge`。

## 使用位置

打开 `http://127.0.0.1:8000/static/Chat4o5-Modern.html`，左下角 Settings → QQ 接入。Tools 中的 QQ 入口也进入相同设置分类。

修改主面板的开关或数值后，点击「保存并应用」。不需要手动重启。群回复开关、邀请同意和拒绝分别立即提交。

## QQ 聊天命令与同步

仅已配置的主人在好友私聊中可以查看或修改 QQ 设置，群内和其他联系人没有权限。命令由服务端解析，不交给模型决定是否执行。普通自然语言对话不会直接修改开关。

| 命令示例 | 效果 |
| --- | --- |
| `/settings` 或 `/设置` | 查看真实当前设置及用法 |
| `/set memory on` / `/设置 记忆 开启` | 主人私聊共用长期记忆；off/关闭可取消共享 |
| `/set mention on` | 群内仅 @回复，off 表示接受已授权群中的普通文字 |
| `/set invites on` | 自动接受主人入群邀请 |
| `/set owner_group on` | 主人首次 @授权新群 |
| `/set cooldown 3` | 普通消息冷却 3 秒 |
| `/set history 12` | 近期上下文 12 轮 |
| `/set timeout 180` | 生成超时 180 秒 |

英文布尔值支持 on/off、true/false、1/0；中文支持 开/关、开启/关闭。现有 `/groups`、`/group allow 群号`、`/group block 群号`、`/requests`、`/approve 邀请编号`、`/reject 邀请编号` 仍可使用。

QQ 自动回复总开关只允许通过网页设置，避免关闭接入后无法通过 QQ 恢复。账号、密钥和模型不通过聊天命令修改。

聊天命令和网页都调用 `QQBridge.update_controls`，使用相同校验、保存文件、运行时设置与响应器配置；群回复授权也共用同一数据库。设置变更带内容版本，网页保存时提交读取到的版本，发生并发变更时返回 409，保留用户表单而不覆盖服务器新值。打开 QQ 设置分类且网页可见时每 5 秒同步；回到窗口也检查同步。没有未保存修改时直接显示新值，有修改时提示重新读取。

新增回归验证通过：QQ 命令更新后网页读取新值、网页更新后 `/settings` 返回新值、旧表单冲突不覆盖、中文命令、参数越界拒绝、主人私聊权限及重启恢复。共 80 项 QQ 测试通过。

## 运行依赖

目前消息链路是 QQ → 本机 NapCat → 本机 Saya 后端 → 模型 → NapCat → QQ。必须让电脑开机、保持网络且不休眠，同时运行 NapCat（含机器人 QQ 登录）和 Saya 后端。当前使用 API 模型，模型服务也必须可用；本机仍负责消息接收、权限、记忆、排队和发送。

浏览器网页可以关闭，关闭网页不会停止后台 QQ 服务。退出 NapCat、关闭后端、电脑关机或休眠都会使自动回复中断。仅在手机 QQ 登录机器人账号并不能运行 Saya 自动回复。启动入口是项目内 `.runtime/napcat/start-all.ps1`；长期无人值守运行需要保持主机在线，或将服务和相应数据迁移到持续在线的设备。

| 设置 | 效果 |
| --- | --- |
| 启用 QQ 自动回复 | 暂停或恢复消息处理，保留登录、记录及群授权 |
| 主人私聊共用长期记忆 | 开启后，主人好友私聊接入网页端个人长期记忆；关闭后使用独立会话。主人身份识别始终保留 |
| 仅在群内 @时回复 | 开启时仅接受结构化 @；关闭后接受已授权群中符合发送者规则的普通文字 |
| 自动接受主人入群邀请 | 主人邀请自动通过，其他邀请进入审核列表 |
| 主人首次 @授权新群 | 主人在新群 @机器人时开启回复，不覆盖手动关闭的群 |
| 普通消息冷却 | 0–3600 秒；主人管理命令继续免冷却 |
| 近期上下文 | 1–50 轮，控制之后的上下文读取长度 |
| 生成等待上限 | 1–900 秒 |
| 群与入群邀请 | 显示已加入群、逐群回复开关和待审核邀请 |

个人长期记忆共享仍限定于已配置主人的好友私聊。群聊和其他联系人不读取个人长期记忆。关闭记忆共享不会删除已有长期记忆或 QQ 聊天记录。

## 保存和访问

非敏感开关保存在 `knowledge_base/qq/settings.json`，优先于 `.env.qq` 中同名选项，服务重启后自动恢复。连接地址、认证密钥、机器人及主人账号仍在本地连接配置中管理，网页不返回认证密钥。网页中的账号信息用于核对。

主网页在本机同源环境自动建立一小时有效的 HttpOnly、SameSite=Strict 设置会话，无需粘贴管理 Token。不允许远程地址、不同源端口、其他网站或伪造 Host 通过该方式管理；旧管理 Token 接口仍兼容。

当前有消息排队、生成或发送时，保存返回「请等待当前回复完成后再保存」，避免修改记忆权限影响正在执行的回复。原子写入失败时保留原设置；启动时发现损坏的设置文件停止 QQ 处理，防止意外恢复到环境里的开启状态。
