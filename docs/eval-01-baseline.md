# 01｜环境、依赖、测试与启动基线

报告写入 `evaluation_results/01-baseline.md`。

## 目标

确认新环境能否理解、安装、测试并启动项目，为后续评测建立可信基线。

## 任务

1. 记录提交、分支、工作区状态；检查 README 的安装、配置、启动、停止和排障说明是否准确。
2. 检查文档中文编码；区分源码、运行数据、日志、备份、上传、缓存和密钥文件。
3. 检查 `.gitignore` 是否覆盖字节码、日志、密钥、Cookie、本地数据库、上传和运行产物。
4. 核对 Python 版本、必要依赖、可选 GGUF/视觉/embedding 依赖。验证缺少可选依赖时能否安全降级。
5. 用不向源码目录写 `.pyc` 的方式解析所有 Python 文件；统计测试文件和用例。
6. 执行完整测试，记录通过/失败/跳过/耗时；确认测试不会访问真实互联网或真实个人数据。
7. 按文档启动服务，验证主页面、静态资源、OpenAPI、至少一个只读 API 和 404。
8. 验证未配置本地模型、embedding、Brave、TTS、翻译时仍可启动。
9. 验证重复启动、端口占用、正常停止；检查启停是否改写知识库或制造异常数量备份。

## 最低用例

`BASE-01` 新环境按说明可安装；`BASE-02` 测试工具有明确依赖；`BASE-03` Python 全部可解析；`BASE-04` 测试套件可执行；`BASE-05` 服务和首页可访问；`BASE-06` 可选能力缺失可降级；`BASE-07` 启停不改业务数据；`BASE-08` 密钥和运行数据未误入版本管理。

无法启动、语法错误、默认启动破坏数据或泄露秘密均按 P0，并建议暂停后续动态评测，但静态阶段继续。
