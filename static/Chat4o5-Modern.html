连接与记忆

关闭后暂停接收和回复 QQ 消息，保留账号、群授权和聊天记录。

主人好友私聊可读写网页端长期记忆。主人身份始终识别；群聊及其他联系人仍隔离。

思考、记忆与搜索（主人私聊）

与网页共用记忆库、检索和写入链路。数量和 token 预算是每次检索上限，模型按问题选择相关内容，不会把全部记忆无条件塞入上下文。群聊仍隔离个人记忆，游戏及外部连接器执行不开放。

按需查询、读取记忆和网页；关闭时使用固定召回与搜索模式。

明确要求记住会按网页规则写入，候选记忆可在 QQ 确认；关闭后只读。

命令示例：/set thinking high、/set memories 50、/set budget 12000、/set search auto；单次操作：/recall 关键词、/search 内容、/remember 内容、/memories。

群聊方式

开启时只回应 @机器人；关闭后回应已授权群的所有可接收文字。

主人邀请成功后开启该群回复；其他人的邀请仍待审核。

兼容 QQ 直接入群的情况。主人在新群明确 @机器人即可开启回复；不覆盖手动关闭。

会话与响应

每批首条关联提问，群内只提醒一次；明确不支持引用时使用文字关联。

开启后可用 /status、/tasks、/cancel 查看和取消当前会话任务。已保存的记忆和已发送的消息不会自动撤回。

默认关闭。仅主人共享好友私聊可修改记忆、预览删除或“不再使用”，并确认具体条目；保存记忆关闭时仍只读。“不再使用”会从新话题继续，原聊天文件保留。

自然策略会把中等长度的完整段落分条，合并碎句；旧结果保留原分段。普通聊天不主动附带操作指令或续读编号。可说“继续说”，或主动用 /topics 查询未完话题，再用 /continue 结果编号续读；不重新搜索、生成或保存记忆。结果保留24小时，每会话最多8份、全局128份。代码或链接可能超过长度目标，仍受单条硬上限限制。设置命令：/set split natural、/set delivery chat、/set quote on、/set bubble 240、/set bubbles 3。

设置保存到本机，应用后无需重启。

QQ媒体（图片、文档与语音回复）

视觉模型复用现有本机API配置。

Using the bot

                
Start a Minecraft Java server, fill host/port, press Start. Commands: follow / unfollow / come / goto x y z / collect dirt 3 / mine nearby / eat / drop one / swim / attack nearest / status / stop. Follow stays enabled across other tasks until unfollow or stop.

                
Or connect any external bot

                
POST /api/bridge/minecraft/status  {"text": "bot at spawn, health 20"}

                
GET  /api/bridge/minecraft/commands?take=5

                
Any source id works (a-z 0-9 _ -). A source appears once it pushes its first status.
