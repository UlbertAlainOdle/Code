# 四项功能修复结果（2026-09-28）

## 已完成

1. 临时聊天：统一阻断已有会话历史、长期记忆、项目、打卡、日记、助手角色资料和游戏桥接上下文；不创建磁盘会话、不登记项目会话、不同步凭证。保留本轮输入、显式附件和按用户设置获取的网页内容。临时会话标记不会覆盖浏览器的普通会话编号。Listener 有独立记忆写入流程，临时模式下会提示先退出 Listener。
2. 备份恢复：校验和与压缩内容来自同一份临时文件快照；普通备份拒绝无效JSON；恢复前的安全备份保留损坏文件原始字节，避免阻断恢复。修正目标列表恢复后被赋成None的问题，省略恢复范围时沿用预览范围，目标/打卡恢复和重载期间阻止并发写入覆盖。
3. 目标与打卡：原子写入、刷新磁盘、同一管理对象的写入串行化、失败时回滚内存；保存失败返回507与saved=false，界面提示错误而不继续成功流程。新增目标失败保留输入。目标状态变化保存status_history，重新开始后再次完成使用新日期；同状态编辑不会重置完成时间。
4. 引用核验：明确展示为词面匹配，检测明显的否定、增减方向、数值单位及简单英文主体冲突；证据按句比较，避免从邻句拼凑支持信息；显示冲突原因及证据摘录。兼容旧的supported/pass字段，但界面不再称其为“原文支持/事实校验通过”。
